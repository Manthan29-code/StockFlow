StockFlow Application Icons
===========================

Place your logo/icon files in this directory:
c:\MyProject\StockFlow\client\build\

1. Windows Application & Installer Icon (.ico):
   File name: icon.ico
   File path: client/build/icon.ico
   Required format: .ico (Windows Icon format)
   Recommended dimensions: Multi-size ICO containing 256x256, 128x128, 64x64, 48x48, 32x32, 16x16
   (Minimum master resolution: 256x256 px)

2. Window & Taskbar Icon (.png):
   File name: icon.png
   File path: client/build/icon.png
   Required format: .png (with transparent background)
   Recommended dimensions: 512x512 px or 256x256 px

Tip:
If you have a PNG logo, you can convert it to a high-quality multi-size icon.ico for Windows using free tools like:
- https://convertico.com/
- https://cloudconvert.com/png-to-ico
- Or via ImageMagick: magick convert logo.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico
